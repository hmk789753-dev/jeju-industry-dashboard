# 제주 업종별 관광 트렌드 대시보드

제주 관광객이 어떤 업종(음식점·카페·숙박·관광명소 등)을 찾는지, 언제·어디서·얼마나 늘거나 줄었는지 보여 주는 웹 대시보드입니다.

- 데이터 기간: 2024.01 ~ 2026.09 (검색어 데이터는 2026.08까지)
- 서버 없이 동작하는 정적 페이지입니다. (HTML + JavaScript, 차트: Apache ECharts 5.5.0)
- 휴대폰에서도 볼 수 있습니다. 좁은 화면에서는 필터가 접혀 있고 「필터 펼치기」로 엽니다.

## 주요 기능

- 기간·지역·지표·업종 필터 (필터 상태가 주소에 저장되어 「링크 복사」로 같은 화면을 공유할 수 있음)
- 업종 구성·점유율, 업종 증감 순위, 업종별 계절성, 읍면동 지도, 인기 장소 지도
- 검색 관심도와 실제 도착 비교, 인기 장소 TOP10, 뜨는 장소·지는 장소
- 보고서 다운로드: 전체 보고서 또는 요약 1장(A4), HTML 또는 PDF(인쇄)

## 꼭 알아 둘 점

- 2026년 도착 수는 입도 관광객보다 크게 늘어 수집 기준 변화가 의심됩니다(원인 미확인). 그래서 비교는 점유율(%p)을 기본으로 하고, 증감률은 참고로만 보여 줍니다. 「2026년 제외」 옵션이 있습니다.
- 관광객·도민 구분 기준은 확인되지 않았습니다. 관련 값은 상대 비교용으로만 표시합니다.
- 인기 장소 위치는 정확한 좌표가 아니라 읍면동 중심 근처의 대략 위치입니다.

## 파일 구성

| 파일 | 내용 |
|---|---|
| index.html, style.css | 화면 뼈대와 스타일 |
| js/*.js | 화면 동작 (화면별로 나뉨, 아래 표) |
| lib/echarts.min.js | 차트 라이브러리 |
| data/industry_data.js | 월 × 읍면동 × 업종 집계 |
| data/places_top.js | 인기 장소 후보 |
| data/geo_data.js | 제주 읍면동 경계 |
| data/search_index.js | 검색어 관심도 |

### js 폴더 (index.html 이 이 순서로 읽음)

| 파일 | 맡은 화면 |
|---|---|
| core.js | 공통: 데이터 읽기, 상수, 숫자 서식, 색, 필터 상태, 집계, 차트 공통 도구 (맨 먼저) |
| filters.js | 사이드바 필터, 기간 달력 |
| overview.js | 한눈에 보기 |
| change.js | 업종 구성·연도별 점유율, 업종 증감 순위 |
| season-map.js | 업종별 계절성, 지역 지도 |
| search.js | 검색 관심도 vs 실제 도착 |
| places.js | 인기 장소 TOP10, 뜨는·지는 장소, 인기 장소 지도 |
| summary.js | 분석 요약, 지표 설명 |
| report.js | 보고서 다운로드 |
| main.js | 전체 갱신, 메뉴, 검색창, 주소 저장, 첫 화면 그리기 (맨 마지막) |

모든 파일이 같은 전역 공간을 쓰므로 core.js 는 맨 앞, main.js 는 맨 뒤에 두어야 합니다.
